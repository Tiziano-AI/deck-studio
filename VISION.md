# Deck Studio

Help someone communicate something worth understanding, deciding or doing.
The result is an audience-ready artifact, not merely a set of slides.

An agent can begin with a vague need, approved material, a deck to revise, a
different required format or an accepted release. It resolves only the decisions
still missing, keeps meaning stable through visual composition, inspects the
result and delivers usable files. No mandatory interview, three-cover exercise
or repeated approval ceremony substitutes for judgment.

A local HTML deck and, when wanted, a screenshot PDF are complete outcomes.
Editable and accessibility-first formats belong to their appropriate artifact
tools. Hosting is an optional continuation, not a prerequisite for creation.

For hosting, agents manage and humans view. Public decks are the front door;
an optional key opens a selective collection. The gallery makes decks and their
covers prominent, not technical status. It is neither a web editor nor an admin
cockpit. Individual decks retain their own design; site branding is configuration.

The product is reusable without the author's workstation, accounts, private
library or deployment. One source owns the skill, producer and gateway. Native
plugins expose that capability without installing services or publishing content
behind the user's back.
