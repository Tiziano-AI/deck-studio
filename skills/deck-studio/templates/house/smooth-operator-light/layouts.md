# Smooth Operator Light layouts

- Title: product mark, compact mono kicker, large Raleway thesis, right-side evidence/control-plane summary.
- Section: thin magenta route line, section label, one sentence about the operator decision ahead.
- Claim: large claim, two evidence cards, one mono proof rail with source aliases or run states.
- Evidence ledger: three to five rows with lane, committed support, artifact, owner, and next action.
- Workflow map: left-to-right typed ingress, run supervisor, specialists/tools, response bundle, export.
- Comparison: two or three columns with a clear decision axis and one cyan verification marker per column.
- Artifact/export: document or bundle frame, manifest fields, page/file counts, and readiness state.
- Close: recommendation plus explicit next operator action, never a generic thank-you slide.

Density: high. Strengths: evidence ledger, workflow map, comparison, operator brief. Weak cases: low-text stage keynote moments, photo-led campaigns.

Use only structures supported by the locked content. Named architecture components and evidence fields above are possible composition slots, not mandatory product claims. Preserve qualifications and sources through any split; a blank slot must be redesigned, not filled with invented data.
