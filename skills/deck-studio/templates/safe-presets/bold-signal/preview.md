# Bold Signal preview guidance

Consider this recipe when the brief benefits from: keynote openers, launch decks, confident pitches.

Visual signature: dark gradient with a single loud card and oversized numbering.

When previewing, use actual locked content that tests the intended composition, including a dense or evidence-bearing slide when relevant. Keep meaning identical across visual candidates and template metadata outside the slide. No fixed preview count or human approval gate is imposed by this recipe.
